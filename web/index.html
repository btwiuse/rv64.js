rv64.js RISC-V Linux, entirely in your browser

Rust · WebAssembly · RV64GC

Boot Alpine Linux in your browser.

No server-side emulator. The CPU, devices, and JIT execute locally in this tab. Image downloads are cached by your browser.

CPUReady · worker
NETNetwork idle
rv64.js console

Run it locally

nix develop -c web/prepare-images.sh
cargo build -p rv64-wasm --target wasm32-unknown-unknown --release
python3 -m http.server -d . 8000
# open http://localhost:8000/web/

The demo uses the current direct-boot kernel and Alpine root image. See the README for native and Node examples.
